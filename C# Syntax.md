## C# Syntax

Here is a simple of a C# code structure:
```C#
using name space;

namespace HelloWrold{
    class Program{
        static void Main(Satring[] args){
            Console.WriteLine("Hello world");
        }
    }
}
```
Here are some features:
- using System means that we can use classes from the System namspace
- namespace is used to organize your code, and it is a container for classes and other namespace
- the curly braces {} marks the beginning and the end of a block of code
- class is a container for data and methods, which brings functionality to your program.
- Any code inside the curly brackets {} of Main method will be executed.
